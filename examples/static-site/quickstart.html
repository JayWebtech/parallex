Quickstart

  1. Create a testnet account and fund it with Friendbot.
  2. Install the SDK: npm install demo-wallet-sdk (fictional).
  3. Request a quote, then submit the payment.
const quote = await wallet.quote({ to: destination, amount: '10' });
const tx = await wallet.send(quote);
